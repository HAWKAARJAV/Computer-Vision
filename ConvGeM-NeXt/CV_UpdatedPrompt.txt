IMPORTANT CONTEXT
=================
This project reproduces the ConvGeM-NeXt plant disease classification architecture from:

https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2026.1763739/full

The current baseline architecture is:

Input 224×224×3
    ↓
ImageNet normalization
    ↓
ImageNet-pretrained ConvNeXt-Base
    ↓
final feature map
    ↓
learnable GeM pooling (p initialized to 3)
    ↓
Linear 1024→1024
    ↓
BatchNorm1d
    ↓
ReLU
    ↓
Dropout(0.3)
    ↓
Linear 1024→num_classes

The existing project already contains training/evaluation utilities. DO NOT destroy existing functionality.

GOAL
====
We now need to turn this into a proper architectural ablation study with FOUR experiments.

The purpose is to demonstrate two genuine architectural improvements over the paper baseline:

1. Multi-Scale Feature Fusion (MSFF)
2. Channel + Spatial Attention (lightweight CBAM-style attention)

The four experiments must be:

EXPERIMENT A — BASELINE
-----------------------
Original ConvGeM-NeXt exactly as currently implemented.

Architecture:
ConvNeXt-Base
→ final Stage 4 only
→ GeM
→ existing classifier head

This is the control/baseline.

EXPERIMENT B — BASELINE + MULTI-SCALE FEATURE FUSION
-----------------------------------------------------
Use ConvNeXt Stage 2 + Stage 3 + Stage 4.

Expected torchvision ConvNeXt-Base feature shapes for 224×224 input:

Stage 2: 28×28×256
Stage 3: 14×14×512
Stage 4:  7×7×1024

Create a Multi-Scale Feature Fusion module:

Stage 2:
28×28×256
→ 1×1 convolution
→ 28×28×256

Stage 3:
14×14×512
→ 1×1 convolution 512→256
→ 14×14×256
→ upsample ×2
→ 28×28×256

Stage 4:
7×7×1024
→ 1×1 convolution 1024→256
→ 7×7×256
→ upsample ×4
→ 28×28×256

Concatenate along channels:

28×28×256
+
28×28×256
+
28×28×256
=
28×28×768

Then use a 3×3 convolution to fuse:

28×28×768
→ 28×28×256

Then:
→ GeM over the 28×28 spatial dimensions
→ 256-dimensional feature vector

Because the original classifier expects 1024 features, change only the first classifier projection:

Linear 256→1024
→ BatchNorm1d
→ ReLU
→ Dropout(0.3)
→ Linear 1024→num_classes

Do NOT change anything else.

EXPERIMENT C — BASELINE + CHANNEL/SPATIAL ATTENTION
---------------------------------------------------
Keep the original ConvGeM-NeXt feature extraction unchanged:

ConvNeXt Stage 4 only
→ 7×7×1024

Insert a lightweight CBAM-style attention block BEFORE GeM.

Implement:

1. Channel attention
2. Spatial attention

Channel attention:
- Global average pooling over H,W
- Small bottleneck MLP
- ReLU
- projection back to 1024 channels
- sigmoid
- multiply original feature map by channel attention weights

Spatial attention:
- compute channel-wise average map
- compute channel-wise max map
- concatenate those two maps
- apply a small convolution, preferably 7×7
- sigmoid
- multiply feature map by spatial attention map

So:

ConvNeXt Stage 4
→ Channel Attention
→ Spatial Attention
→ GeM
→ original classifier head

Do NOT change the classifier dimensions for Experiment C.

EXPERIMENT D — MULTI-SCALE FUSION + ATTENTION
---------------------------------------------
Combine Experiments B and C.

Pipeline:

ConvNeXt
    ↓
Stage 2 + Stage 3 + Stage 4
    ↓
Multi-Scale Feature Fusion
    ↓
28×28×256
    ↓
Channel Attention
    ↓
Spatial Attention
    ↓
GeM
    ↓
256 features
    ↓
Linear 256→1024
    ↓
BatchNorm1d
    ↓
ReLU
    ↓
Dropout(0.3)
    ↓
Linear 1024→num_classes

This is the FINAL proposed architecture.
